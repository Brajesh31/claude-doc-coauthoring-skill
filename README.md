# DocCoauthoring

Guide users through planning, drafting, refining, and reader-testing substantial documentation such as proposals, technical specifications, product requirements, and decision records.

## What this skill covers

- Practical guidance for applying doc coauthoring workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use the instructions in `SKILL.md` as the primary reference.

## Installation

Add this skill directory to the skills location supported by your AI coding assistant, then make the skill available to the assistant.

## Usage

Invoke the skill when working on tasks related to doc coauthoring. Provide the relevant project context, constraints, and expected outcome. Review generated changes before applying them.
