# Section Refinement Guide

Use this loop for each section.

1. State the section's job in one sentence.
2. List the facts and decisions it must contain.
3. Identify missing evidence or unresolved assumptions.
4. Propose a concise structure.
5. Draft the section.
6. Ask for targeted feedback.
7. Apply only the requested changes and necessary consistency fixes.
8. Mark the section accepted when the user confirms it.

## Revision principles
- Preserve accepted wording unless a contradiction requires change.
- Prefer concrete nouns and verbs over vague abstractions.
- Remove repeated explanations.
- Put the conclusion before supporting detail when readers need to act.
- Use tables for comparisons, not as a substitute for analysis.
- Keep requirements testable and decisions traceable.

## Change log
For multi-session documents, track meaningful changes with date, section, change, and reason. Do not claim approval unless the user explicitly confirms it.
